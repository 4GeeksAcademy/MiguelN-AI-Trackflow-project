# Rule: Next.js architecture and conventions

Scope: Applies to all UI code in this repository.

Requirements:
- Use Next.js App Router only. Do not use a pages directory pattern.
- Use TypeScript everywhere and avoid any.
- Place shared type definitions in interfaces.
- Use Tailwind CSS for styling.
- Components must be functional components with named exports.

Use this rule when building new UI features or reviewing existing code.
